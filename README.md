# Code For Distance Formula

## This program does the distance formula for you with your given inputs.

## How to Run
1. Open google colab
2. Run the code
3. Input the variables that are asked for(x1, y1, x2, and y2)
4. Check the distance displayed on the screen

## Input Needed
- x1
- y1
- x2
- y2

## Sample Output
What is the value of x1: 2
What is the value of y1: 3
What is the value of x2: 7
What is the value of y2: 8
The distance for between your given points is, 7.07
